# C ABI reference

Every binding (Python, .NET, Swift, Node) — and the Rust FFI suite
itself — wraps the same flat C ABI declared in
[`include/tts_wrapper.h`](../include/tts_wrapper.h) (auto-generated by
cbindgen from the Rust source; `cargo build` refreshes it).
[bindings/README.md](../bindings/README.md) covers loading conventions
and the cross-binding test matrix; `bindings/c/tts_abi_harness.c` is a
reference harness compiled with `-Wall -Wextra -Werror`.

## Symbols

| Area | Symbols |
|---|---|
| Lifecycle | `tts_create`, `tts_destroy` |
| Synthesis | `tts_speak`, `tts_speak_ssml`, `tts_speak_sync`, `tts_synth_to_bytes`, `tts_synth_to_wav`, `tts_free_bytes` |
| Control | `tts_stop`, `tts_pause`, `tts_resume` |
| Settings | `tts_set_voice`, `tts_set_rate`, `tts_set_pitch`, `tts_set_volume` |
| Events | `tts_set_on_audio`, `tts_set_on_boundary` (7-arg incl. `estimated`), `tts_set_on_mark`, `tts_set_on_viseme`, `tts_set_on_start`, `tts_set_on_end`, `tts_set_on_error` |
| Enumeration | `tts_get_voices`/`tts_free_voices`, `tts_get_engine_count`, `tts_get_engines`/`tts_free_engines`, `tts_get_engine_setups_json` |
| Model registry | `tts_get_sherpa_models_json` |
| Errors | `tts_get_last_error`, `tts_get_last_error_code`, `tts_get_last_error_detail_json`, `tts_free_string` |
| Credentials | `tts_check_credentials` (1 = Verified, 0 = Rejected, 2 = Unverified, −1 = failed → detail) |

Conventions that hold across the ABI:

- **Null-hardening:** every setter accepts a null ctx as a no-op; every
  out-pointer API returns non-zero instead of crashing on null args.
- **Ownership:** arrays and byte buffers returned by the ABI are freed
  by the matching `tts_free_*`; JSON strings by `tts_free_string`;
  error strings are borrowed from the ctx.
- **Callbacks:** cdecl C function pointers taking a `void *userdata`;
  payload contracts are documented per-callback in the header.
- **Word boundaries:** `cb(word, byte_offset, byte_len, start_s, end_s,
  estimated, userdata)` — UTF-8 byte offsets into the submitted text
  (SAPI reports UTF-16 units; Azure passes its own units through).

`tts_synth_to_wav` returns one PCM WAV buffer at the synthesized sample
rate for cloud and Sherpa-ONNX engines. Free it with `tts_free_bytes`.
`tts_synth_to_bytes` keeps its original engine-specific byte format.

`tts_get_sherpa_models_json` returns the bundled registry JSON keyed by model
ID. Free the returned string with `tts_free_string`. A build without Sherpa-ONNX
returns null and sets the global `EngineNotAvailable` error.

## Error codes (GH #69)

`tts_get_last_error_code` returns a stable, append-only u32
(see `src/error_codes.rs`):

| Code | Name | Meaning |
|---|---|---|
| 0 | `Unknown` | nothing recorded / legacy path |
| 1 | `MissingConfiguration` | required setting missing — detail carries `fieldKey` |
| 2 | `InvalidConfiguration` | malformed value (e.g. credentials not valid JSON) |
| 3 | `CredentialsRejected` | provider refused the credentials (401/403) |
| 4 | `NetworkError` | unreachable (DNS/timeout/TLS/refused) |
| 5 | `ModelNotFound` | local model/voice file missing |
| 6 | `MissingNativeDependency` | engine DLL/.so failed to load |
| 7 | `EngineNotAvailable` | unknown id / compiled out |
| 8 | `LanguageNotSupported` | engine rejected the language |
| 9 | `EngineFailure` | any other engine failure |

`tts_get_last_error_detail_json` returns
`{"code","name","message","displayMessage","engineId","fieldKey"}` —
the message is secret-redacted; `displayMessage` is a safe,
display-ready hint.

## Example

```c
#include "tts_wrapper.h"
#include <stdio.h>

void on_audio(const uint8_t* chunk, uintptr_t size, void* userdata) {
    printf("Audio chunk: %zu bytes\n", size);
}

void on_boundary(const char* word, int32_t offset, int32_t len,
                 float start, float end, int32_t estimated, void* userdata) {
    printf("Word '%s' %d+%d %.3f-%.3f %s\n", word, offset, len, start, end,
           estimated ? "(estimated)" : "(measured)");
}

int main(void) {
    tts_ctx* ctx = tts_create("openai", "{\"apiKey\":\"your-key\"}");
    if (!ctx) {
        fprintf(stderr, "create failed [%u]: %s\n",
                tts_get_last_error_code(NULL), tts_get_last_error(NULL));
        return 1;
    }
    tts_set_on_audio(ctx, on_audio, NULL);
    tts_set_on_boundary(ctx, on_boundary, NULL);
    tts_set_voice(ctx, "alloy");
    tts_speak_sync(ctx, "Hello world");
    tts_destroy(ctx);
}
```

Build & run the harness:

```bash
cargo build --release
make -C bindings/c test
```

### G2P bundle provisioning (`tts_provision_sherpa_g2p_bundle`)

For non-English piper models whose language has a validated VoiceGarden
bundle (German today), call once during model installation so the voice
speaks offline on first use: `bool tts_provision_sherpa_g2p_bundle(const
char *model_id)`. True = bundle present in the cache afterwards (the
cache honors `VOICEGARDEN_LEXICON_DIR`; a miss downloads 13–19 MB and
verifies the manifest sha256). The registry export
(`tts_get_sherpa_models_json`) carries `g2p_enabled` per model for
download-eligibility gating (snake_case → `g2pEnabled` in Swift's
convertFromSnakeCase decoder).
